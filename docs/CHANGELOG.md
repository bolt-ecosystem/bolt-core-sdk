# Bolt Core SDK Changelog

## Current Public State

- The SDK is the shared Rust authority for Bolt protocol-critical code.
- Active crates include `bolt-core`, `bolt-btr`, `bolt-transfer-core`,
  `bolt-transfer-policy-wasm`, `bolt-protocol-wasm`, `bolt-app-core`, and the
  local PAKE feasibility spike.
- Retired desktop UI crates have been removed from the active workspace.
- Governance trackers and private audit evidence are not part of the public SDK
  documentation.
